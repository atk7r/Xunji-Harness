request bodies, PoC recipes, and undisclosed working material. Its entries are
ignored by Git and must never be pushed to the public repository.

Only this README and `.gitkeep` belong to the public scaffold. A local match is a
lead, not a finding; target-facing use still requires scope, privacy, guard,
artifact recording, controls, and the evidence gate.
