# Mechanism-Class Lexicon Scaffold

This file contains only generic canonical names used by Xunji templates and
validators. Product facts, target identifiers, payloads, exploit steps, and
engagement observations belong in operator-local ignored entries.

## Canonical families

- authentication-bypass
- authorization-bypass
- injection
- insecure-deserialization
- server-side-request-forgery
- file-upload
- path-traversal
- information-disclosure
- security-misconfiguration
- client-side-injection

Use the narrowest justified class name in local knowledge and run records. A class
name is vocabulary, not evidence and not permission to test a target.
